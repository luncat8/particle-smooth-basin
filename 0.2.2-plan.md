# 0.2.2 buoyancy and thermal scenario controls

## goal

Make size-dependent buoyancy strong enough to explore, expose its overall strength separately, and make the thermal-size / Archimedes sign combinations quick to compare. Keep the engine DOM-free, the page file-friendly, and the physics tunable live.

## controls and model

- Archimedes size exponent: -10..+10, default 0. Buoyant acceleration scales with `(radius / typicalRadius)^exponent`; bound the resulting lift multiplier to 1/8..8 to keep extreme slider values usable.
- Overall buoyancy strength: 0..2×, default 1×. Zero removes the Archimedes term; one preserves the existing density-based balance.
- Thermal source relaxation and bead-to-bead conduction get separate 0..4× controls, both defaulting to 1×.
- Quick presets update only thermal size and Archimedes size coupling, leaving buoyancy and heat rates available for tuning:
  - hot shrinks / flow only: size -1, Arch 0
  - big floats: size 0, Arch +4
  - convection pairs: (-1, -4) and (+1, +4), so hot beads rise
  - stable pairs: (-1, +4) and (+1, -4), so hot beads sink

## validation

- Verify buoyancy 0, 1, and 2× on a neutral fully submerged bead; default 1× preserves the existing equilibrium.
- Verify Archimedes size coupling clamps to -10..+10 and extreme lift remains finite and bounded.
- Verify source-only and conduction-only heating independently, plus zero-rate stability.
- Smoke-test every quick preset and manual control updates in the classic-script browser bundle.
- Run the physics bench, including an extreme size-coupling stress scene; keep the existing no-NaN and spawn-cap checks passing.
