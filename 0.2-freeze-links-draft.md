# Thermal-link design note

This note is incorporated into `0.2-plan.md`; it supersedes the earlier manual freeze/thaw proposal.

- Beads bond automatically when a near-contact pair is cool (mean temperature below 0.55).
- Bonds are stable PBD distance constraints, not stiff force springs. Their rest distance is stored relative to the current sum of radii (at least 1.01×) so thermal sizing and contact separation do not fight the bond.
- Bond stiffness rises as the pair cools and fades to zero as it warms, so the same mechanism provides freezing and thawing without a separate key or phase toggle.
- Pair keys are deduplicated; particle indices remain append-only. The contact relaxation loop solves contacts first and bonds second in each iteration.
- No fracture or manual region selection in this version.
