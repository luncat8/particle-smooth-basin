# 0.2.2 buoyancy and thermal-scenario worklog

## review of 0.2.1

The previous size-coupling model correctly kept `archSize = 0` as a no-op and preserved the original density-based Archimedes balance. The wider exponent request makes direct powers very large (`1.81^10` is about 378), so the extended control keeps the power law but bounds the lift multiplier to 1/8..8. A separate overall buoyancy control leaves the default (`1×`, size coupling `0`) unchanged.

## implementation

- Extended Archimedes force vs size from -1..+1 to -10..+10, with 0.1 slider steps and a bounded lift multiplier.
- Added a live 0..2× buoyancy strength slider; zero removes Archimedes lift and 1× preserves the prior model.
- Split thermal source relaxation from bead-to-bead conduction into independent 0..4× controls.
- Added quick scenarios for shrink-only flow, big floaters, both convection sign pairs, and both stable sign pairs. Presets change only thermal size and Archimedes coupling; users can keep tuning buoyancy and heat rates.
- Updated the thermal plan, GUI plan, README, and focused Node checks.
