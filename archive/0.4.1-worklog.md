# 0.4.1 GUI presets and clipboard worklog

## Review

Reviewed the 0.4.0 worklog and the two supplied 0.4.0 browser logs. The earlier scene/settings work is present and the logged browser run passed all eight checks and twelve performance cases. This task changes the shipped configuration, so its previous default-specific thresholds and scene-size expectations needed to follow the new default rather than silently testing the old scene.

## Changes

- Added the four requested complete-scene presets, using the provided JSON values. `convectionThermal` is now the app and engine default, including temperature hue enabled. Preset data lives in `js/engine.js`; selecting one applies all settings and re-deals the bed. Defaults selects the first preset.
- Re-centered the visible slider ranges around the new presets, including water at 25–40% and coverage at 8–70%. Capped the Archimedes slider/setter at +2 while retaining its -10 lower bound, centering that range near the preset values.
- Put Heat lifts, Archimedes force vs size, and Buoyancy strength together in a visually grouped control block and prefixed each with ⇑. Any edited slider marks the selected preset as custom.
- Replaced the paste prompt with direct `navigator.clipboard.readText()` use, with explicit empty, invalid JSON, unavailable, and denied-read feedback. Copy behavior is unchanged.
- Updated the smoke check for asynchronous clipboard paste and complete presets. Updated the thermal zone harness to measure the bed's upper 2% quantile (so isolated rising beads do not define the bed surface) and to match the intentionally lighter-bond default. Adjusted default-specific stability and scene-count assertions. Bumped the test version to 0.4.1.

## Validation

`python3 run_tests.py --node-only` passed all six checks: smoke, thermal, bench, thermal-zone, settings, and harness. The shipped scene measured 648 beads, 19 active links, 3 above the water, and a representative bed top at 246 px in the sandbox thermal-zone check. The full passing output is saved at `experiments/logs/0.4.1-tests-2026-10-26-03-17-38.log`.

Not validated: browser-rendered pixels and real-device timings for the new GUI arrangement. The supplied previous browser run is evidence for the earlier build only.
