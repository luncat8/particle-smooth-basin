# 0.2 thermal basin worklog

## review of the 0.1 base

Reviewed the engine, renderer, app, bench, and existing 0.2 freeze-links draft before changing behavior. The base's stable SoA particle indices, typed-array broadphase, pair buffers, fixed-step PBD loop, local sprite rendering, and DOM-free engine were sound seams to keep. The prior freeze draft's manual F/T freeze-all model did not match the new thermal brief; its useful stable-link/PBD idea is retained as automatic temperature-driven cohesion instead.

A broadphase detail needed tightening: widening pair distance alone would miss candidates crossing two grid cells. Cell width now scales with the candidate radius. Also, link rest distances are clamped to at least 1.01× summed radii; measurements showed that using the PBD contact solver's residual overlap as the rest distance makes links fight contacts and causes persistent velocity. Link-normal velocity is damped to keep bonded groups calm.

## plan decisions

- Rewrote `0.2-plan.md` around normalized temperature, temperature-driven size and links, explicit control ranges, local rendering, and measurable validation.
- Preserved the supplied brief as `0.2-thermal-basin-draft.md` and updated the old freeze-link note to document the integrated thermal bond model.
- Added `0.3-plan.md` for a profiled WebGPU port with local assets, validation criteria, and explicit `file://` feasibility checks; no GPU backend was implemented in this step.

## implementation

- `js/engine.js`: per-bead temperature and preallocated heat deltas; cold top and hot bottom sources; pairwise heat exchange; canvas-area coverage-based bed generation; typical-size, average-mass and heat/size settings; temperature-scaled radii and mass; persistent deduplicated PBD bonds whose stiffness fades with heat; bond damping.
- `js/render.js`: cached thermal source gradients, pre-rendered temperature hue sprites, and batched strength-banded bond segments.
- `index.html` / `js/app.js`: native controls for heat exchange, signed thermal size, 30–70% coverage, typical radius, average mass, temperature view, and re-deal.
- `experiments/thermal.js`: focused thermal, size, link, coverage, and cap checks.
- `experiments/smoke.js`: classic-script browser-bundle boot/render/control smoke under a lightweight DOM/canvas mock.
- `README.md` and `experiments/logs/0.2.0.txt` document operation and validation.

## validation

Commands run:

- `node --check js/engine.js && node --check js/render.js && node --check js/app.js`
- `node experiments/thermal.js` — passed zero-rate temperature stability, upper cooling, lower heating, 2× endpoint size ratio for either sign, cold bond creation, warm softening, coverage, and spawn-cap checks.
- `node experiments/smoke.js` — passed bundled boot, repeated frame drawing, controls, and re-deal.
- `node experiments/bench.js` — 810 beads at 1280×800, 0.52 ms/frame, 60-second settle with no NaN, max speed 2 px/s and mean speed 0.3 px/s; splash stress had no NaN. Existing Archimedes equilibrium remained 0.500 for density 0.5 and fully submerged for density 2.0.
- Started the local HTTP preview on port 8080 and confirmed the page and engine asset are served.
